# إفتكس — منصة الهاند ميد

متجر ثلاثي الأبعاد للإكسسوارات والهدايا والشيكولاتة المخصصة. المنتجات معروضة على أرفف زجاجية تقدر تلف حواليها، وكل منتج ليه مجسّم بيلف قدام العميل، والطلب بيتحوّل لرسالة واتساب جاهزة.

## اللي جوه

| الجزء | الملف |
|---|---|
| الصفحة الرئيسية وكل الصفحات | `index.html` + `js/pages.js` |
| المتجر ثلاثي الأبعاد (الأرفف) | `js/store3d.js` |
| المجسّمات المتولّدة برمجياً (22 شكل) | `js/models.js` |
| اصنع منتجك بنفسك | `js/builder.js` |
| المساعد الذكي + تفسير الوصف + توليد الوصف | `js/ai.js` |
| السلة والطلب عبر واتساب | `js/state.js` + `js/pages.js` |
| البيانات (الهبات، الأقسام، المنتجات) | `js/data.js` |
| الإعدادات (واتساب، الشحن، مفاتيح الـ AI) | `js/config.js` |
| لوحة التحكم | `admin.html` |

## التشغيل

الموقع ثابت (static) ومفيش بناء. ارفعه على GitHub Pages وخلاص.
محلياً: `python3 -m http.server 8787` وافتح `http://localhost:8787`.

## تعديل المنتجات

1. افتح `admin.html` (الرقم السري في `js/config.js`).
2. عدّل/ضيف المنتجات مع معاينة 3D.
3. **حفظ في المتصفح** للمعاينة على جهازك، ثم **تحميل data.js** وارفعه مكان `js/data.js`.

## تفعيل الذكاء الاصطناعي الحقيقي

المساعد و"اصنع منتجك" بيشتغلوا بمحرك محلي بدون أي مفتاح. لو عايز Claude أو Gemini:
في `js/config.js` حط المفتاح وغيّر `ai.provider` إلى `'claude'` أو `'gemini'`.
(المفتاح هيكون ظاهر في كود الموقع — استخدم مفتاح محدود الصلاحيات/الرصيد.)

## الهبات (Hubs)

المنصة مبنية كمساحة عرض: في `js/data.js` كل هب له أقسامه. فعّل هب جديد بـ `active: true` وأضف أقسام بـ `hub: 'id'`.
